# หารต้นทุนร่วมให้ยอดตรงบิลทุกเซ็นต์

*ร่าง · ตอนที่ 3 จาก 3*

EKS cluster กลาง, network, AWS Support, tax, Savings Plan ที่ใช้ไม่หมด ไม่มีเจ้าของคนเดียว
ถ้าโยนไว้ในกอง "shared" รายงานต้นทุนต่อโปรเจกต์จะต่ำกว่าความจริงเสมอ

## กฎเป็นข้อมูล ไม่ใช่โค้ด

กฎอยู่ในตาราง `allocation_rules` (มีเวอร์ชันและช่วงวันที่มีผล เหมือน SCD2) แก้ได้จากหน้า Streamlit:

| วิธี | ใช้กับ | ตัวอย่าง |
| --- | --- | --- |
| `usage_driver` | ของที่วัดปริมาณใช้ได้ | EKS หารตาม vCPU-hours ต่อโปรเจกต์ |
| `proportional_direct` | ของที่โตตามขนาดงาน | network, support, tax |
| `fixed_pct` | ข้อตกลงทางธุรกิจ | RI ของ RDS: payment-api 60 / ledger 40 |
| `even` | ไม่มีเหตุผลให้แบ่งต่างกัน | credit |

ปริมาณใช้จริง (driver) **ไม่อยู่ในบิล** ของจริงต้องดึงจาก CloudWatch หรือ OpenCost

## หารเป็นขั้น (step-down)

support กับ tax ควรหารตามยอด "หลัง" หาร network และ EKS แล้ว ไม่ใช่ตามต้นทุนตรงอย่างเดียว
กฎจึงมี `step`: ขั้น 2 ใช้ฐาน = ต้นทุนตรง + ส่วนที่ได้รับจากขั้น 1

กันการหารวน (A หารให้ B แล้ว B หารกลับให้ A) ด้วยโครงสร้าง: pool ต้องเป็นโปรเจกต์ shared หรือ unattributed
และผู้รับต้องไม่ใช่ทั้งสองแบบ ส่วนที่หารแล้วจึงไม่มีทางกลับเข้า pool

## เศษสตางค์: largest remainder

หาร $10 ให้ 3 โปรเจกต์ = 3.33 × 3 = 9.99 หายไป 1 เซ็นต์ คูณหมื่นบรรทัดก็หายเป็นดอลลาร์

1. แปลงยอดเป็นหน่วยเล็กสุด (ใน repo ใช้ 10⁻⁶ USD เพราะบิลจริงมีทศนิยมมากกว่า 2 ตำแหน่ง)
2. ปัดลงทุกส่วน
3. เศษที่เหลือแจกทีละหน่วยให้โปรเจกต์ที่มีเศษมากที่สุดก่อน

ได้ 3.34 + 3.33 + 3.33 = 10.00 พอดี (มี unit test ยืนยันที่ precision 2)

## test ที่สำคัญที่สุดของโปรเจกต์

`assert_allocated_total_equals_bill`: ยอดหลังหารทั้งเดือน = ยอดบิลดิบทั้งเดือน
ผลจริงต่างกันไม่ถึง $0.0001 ทุกเดือน และมี test รองรับ:

- ทุกบรรทัดบิล ยอดหลังหาร = ยอดก่อนหาร
- fixed % ของแต่ละกฎรวมกัน = 100
- ไม่มียอดติดลบ ยกเว้น credit/refund
- 1 บรรทัดเข้าได้ 1 กฎต่อขั้น
- บรรทัดที่หาฐานหารไม่ได้ ยังอยู่ที่เดิม ไม่หาย

## ตรวจย้อนกลับได้ทุกดอลลาร์

`fct_cost_allocated` เก็บ grain = บรรทัดบิล × โปรเจกต์ พร้อม `rule_id`, `rule_version`, `share_pct`, `original_project_id`
หน้า Streamlit ตรวจย้อนกลับเลยไล่ได้ว่า "storefront ได้รับค่า EKS เดือน ส.ค. $748.22 จากบรรทัดไหน ได้กี่ % เพราะ vCPU-hours เท่าไร"
